# Contributing

Bug fixes, portable editing features, and small reusable templates are welcome. Keep the default pipeline lightweight and provider-neutral. Optional tools belong in the catalog unless there is a demonstrated need for core integration.

Run `python -m unittest discover -s tests -v` with NumPy installed. Use synthetic or appropriately licensed media for tests; never upload personal footage, API keys, private transcripts, or unrelated project notes. Include reproduction steps, OS/Python/FFmpeg versions, and what was actually tested. Preserve the upstream MIT copyright notice and attribution.

Avoid irreversible edits to source media, implicit paid calls, or automatic installation of heavy dependencies. Report limitations and keep creative choices reviewable.
